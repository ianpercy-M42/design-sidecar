# Design Sidecar

A hands-free voice design colleague for a phone. Open the page, tap once, and talk.

It listens, answers out loud, and keeps notes in whatever format you dictate. Ask for a review and it applies an elegance critique; ask it to compare two ideas and it argues both. Project agnostic.

The page calls the Anthropic API directly from your browser. Your API key is stored only in that browser and goes nowhere but api.anthropic.com.
